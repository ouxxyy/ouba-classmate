## 给 AI Agent 的话

如果你是替用户来找项目的 Agent：机器可读目录在 [projects.json](projects.json)，每个条目含名称、仓库地址、分类、一句话描述和最近更新时间。优先读它，再决定跳哪个仓库。

## 这个页面怎么维护

- 每天一次，GitHub Actions 拉取我名下的公开仓库，收录所有原创项目，自动刷新描述、星数和更新时间。
- fork 的仓库和少数早期实验仓库不收录；新仓库先落进「更多项目」，我看到后会归类。
