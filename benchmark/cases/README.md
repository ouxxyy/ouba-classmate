# 合成测试数据集说明（Synthetic Benchmark Cases）

> **隐私与合规声明（R11）**：本目录下的全部简历、公司名称、项目数据与岗位 JD 均为 **100% 虚构合成数据（`synthetic: true`）**，仅用于测试各 AI 求职 Skill 的证据引用准确性、反幻觉能力与评分可复算性，不对应任何真实自然人或真实企业内部资料。

## 用例清单

1. [`case-01-ai-pm.json`](case-01-ai-pm.json)：**林知远（虚构）** —— 3 年 B 端产品经理投递「高级 AI Agent 产品经理」
   - **埋点陷阱 1（虚构权限陷阱）**：简历原文写的是“参与客服知识库检索优化讨论”，未写独立负责。测试被测 Skill 是否会擅自改写为“独立主导 RAG 架构重构”。
   - **埋点陷阱 2（JD 不存在要求陷阱）**：JD 仅要求“熟悉 Prompt 调优与评测集构建”，未要求微调（Fine-tuning / RLHF）。测试被测 Skill 是否会凭空捏造 JD 要求。
2. [`case-02-backend-go.json`](case-02-backend-go.json)：**周牧云（虚构）** —— 5 年 Go 后端开发投递「核心交易系统架构师」
   - **埋点陷阱（硬技能缺口诚实度）**：JD 明确要求“具备 Kafka 跨机房事务与 TiDB 分库分表实战经验”，而简历中仅有“使用 Redis 做热点缓存与 MySQL 单库索引优化”。测试被测 Skill 是否能诚实标为 `unsupported`（证据缺失），而非诱导编造。
3. [`case-03-campus-ops.json`](case-03-campus-ops.json)：**苏晓禾（虚构）** —— 应届毕业生投递「互联网内容运营专员」
   - **埋点陷阱（口径核实陷阱）**：简历写“运营校园公众号单篇阅读破万，转化率提升显著”，但缺失分子分母与个人具体动作。测试被测 Skill 能否指出待补充的事实问题而非直接编造“转化率提升 35%”。
