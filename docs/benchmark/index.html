三、六大评分维度口径（每项 0–2 分，满分 12 分）

  • D1 证据引用与反幻觉门禁：0分=无引用约束；1分=仅口头 Prompt 提醒；2分=强制绑定原文行号/段落或 Claim Ledger 且有脚本核验。
  • D2 评分与逻辑可复算性：0分=纯 Prompt 无脚本或 LLM 主观打分；1分=含辅助脚本但核心判断仍波动；2分=由确定性代码公式计算，同输入必得同分。
  • D3 可投递 PDF 简历排版与视觉模板：0分=不导出排版级 PDF 简历；1分=单一基础导出；2分=内置多套专业 HTML/PDF/RenderCV 视觉模板与版式控制。
  • D4 隐私保护与脱敏机制：0分=流向不明；1分=声明本地运行；2分=本地运行且内置 PII 脱敏扫描或显式数据告知页。
  • D5 中文求职生态适配度：0分=仅英文；1分=基础中文支持；2分=深度适配国内招聘平台、中文 JD 话术与中国职场追问。
  • D6 工程完备度与一键可安装性：0分=单文件无规范；1分=标准 SKILL.md；2分=标准 SKILL.md + 自动化单测 + 插件/MCP/CLI 入口。
