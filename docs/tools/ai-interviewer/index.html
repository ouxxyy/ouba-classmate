ouba-classmate 套件核心组件

AI面试大师（ai-interviewer）｜中文语音与文字经历面试陪练（原话引用五维点评）

基于目标岗位 JD 与个人真实经历进行自我介绍 + 三道经历题连环追问，每道题给出引用候选人原话的五维三档点评，并支持同一题重答对比。

★ 在 ouba-classmate 合集主仓点 Star 并一键安装  ·  查看组件源码仓 (ai-interviewer)  ·  查看 12 仓公开横评对比

适用场景

面试前实战演练：害怕面试官追问“你个人到底做了什么”“数据怎么算的”，需要带原话证据引用的复盘教练。

通过 ouba-classmate 套件一行安装

# 推荐：添加合集插件市场或直接安装指定 Skill
claude plugin marketplace add ouxxyy/ouba-classmate
npx skills add ouxxyy/ouba-classmate --skill ai-interviewer

核心特性与实测表现

  • 提供免安装在线语音 Web 版（interview.redboook.cn）与纯文字 Claude Code / Codex Skill 双入口
  • 严格遵循 rules@0.3.0：每条点评必须引用候选人回答原话，支持初答与重答直接对比
  • 新增 seasonal/ 2027 春招与年后跳槽高频压力追问题库包

能力边界与诚实说明

专注训练行为与经历面试，不提供算法白板题评测，也不预测真实招聘方录用概率。
