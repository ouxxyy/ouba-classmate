ouba-classmate 套件核心组件

AI简历优化大师（jd-resume-match）｜可复算评分、原文行号证据引用与 MCP Server

对照目标岗位 JD 逐条审查简历原文证据（L1..Ln），由确定性脚本按 jd-match-rubric/0.1.0 公式复算匹配分，输出结构改写方案与自包含 HTML 体检单。

★ 在 ouba-classmate 合集主仓点 Star 并一键安装  ·  查看组件源码仓 (jd-resume-match)  ·  查看 12 仓公开横评对比

适用场景

投递前体检：想知道自己的简历在目标 JD 下面到底差哪几条证据，拒绝大模型凭空捏造项目数据。

通过 ouba-classmate 套件一行安装

# 推荐：添加合集插件市场或直接安装指定 Skill
claude plugin marketplace add ouxxyy/ouba-classmate
uvx --from "git+https://github.com/ouxxyy/jd-resume-match#subdirectory=mcp" jd-resume-match-mcp

# 觉得有用？在终端 1 秒为开源主仓点亮一颗 Star
gh api -X PUT /user/starred/ouxxyy/ouba-classmate

核心特性与实测表现

  • 唯一提供确定性数学公式复算（floor(100 * Σ(w*c)/Σw + 0.5)）的中文简历匹配工具，270 项单测
  • 每条判定强制绑定简历原文行号（L1..Ln），杜绝把“参与”改成“独立负责”的权限幻觉
  • 内置零依赖 stdio MCP Server（io.github.ouxxyy/jd-resume-match），支持 Claude Desktop / Cursor / Claude Code 一键调用

能力边界与诚实说明

【诚实边界】只输出诊断体检单与改写方案，不直接导出可投递的视觉排版 PDF 简历；中文 CID 字体 PDF 需转文本或 DOCX。
