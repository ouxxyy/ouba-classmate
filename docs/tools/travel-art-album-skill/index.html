核心特性与实测表现

  • 内置厚涂微缩、等距治愈积木、纸艺旅行、编辑旅行摄影×水彩手绘 4 种风格，支持整册统一或逐张混排

能力边界与诚实说明

需要宿主具备本地图片读取与参考图编辑（image-to-image）能力，禁止用纯文本生图冒充参考图重绘。

高频常见问题（FAQ）

用 AI 重绘旅行照片会不会把人物脸部改歪或者覆盖掉我的原图？

工具内置两大防线：一是原始照片目录严格只读不修改；二是强制执行“先看 4 种风格小样确认、再批量制作”门禁，你确认人脸辨识度和画风满意后才会继续。

做出来的 3D 翻页画册需要搭服务器或者长期续费托管吗？

不需要。成品是一个零外部依赖的单文件离线 HTML 画册，发给朋友双击浏览器即可 3D 翻页阅读，也可直接打印导出为 PDF 实体印刷。

任何只支持纯文字聊天的 AI 助手都能跑这个 Skill 吗？

不能。本 Skill 必须运行在具备本地图片读取与参考图编辑（image-to-image）能力的宿主中，工具本身明确禁止用纯文本生图冒充参考图重绘。
