ouba-classmate 套件核心组件

重拍画册（travel-art-album-skill）｜旅行照片艺术化与单文件离线 3D 翻页相册 Skill

将 10–30 张旅行照片先生成 4 种风格小样供用户确认，再批量制作为典藏级单文件离线 3D 翻页 HTML 画册（支持直接打印导出 PDF）。

★ 在 ouba-classmate 合集主仓点 Star 并一键安装  ·  查看组件源码仓 (travel-art-album-skill)  ·  查看 12 仓公开横评对比

适用场景

旅行纪念与作品集：不想让旅行照片躺在相册吃灰，希望在保留人物辨识度的前提下做成可离线翻阅的精装艺术画册。

通过 ouba-classmate 套件一行安装

# 推荐：添加合集插件市场或直接安装指定 Skill
claude plugin marketplace add ouxxyy/ouba-classmate
npx skills add ouxxyy/ouba-classmate --skill travel-art-album-skill

# 觉得有用？在终端 1 秒为开源主仓点亮一颗 Star
gh api -X PUT /user/starred/ouxxyy/ouba-classmate

核心特性与实测表现

  • 内置厚涂微缩、等距治愈积木、纸艺旅行、编辑旅行摄影×水彩手绘 4 种风格，支持整册统一或逐张混排
  • 严格执行“先看小样确认、再批量制作”门禁，原图只读不修改
  • 成品为零外部依赖的单文件离线 HTML 画册，采用精装贴片封面与画廊展签排版

能力边界与诚实说明

需要宿主具备本地图片读取与参考图编辑（image-to-image）能力，禁止用纯文本生图冒充参考图重绘。
