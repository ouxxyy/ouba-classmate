核心特性与实测表现

  • 严格区分品牌名、招聘主体、劳动合同主体与社保缴纳主体
  • 所有结论强制归入 verified / signal / conflict / unknown 四种证据状态，零结果绝不等同于零风险
  • 默认主动检查三类预警：少于 100 人或初创规模、感恩/业绩冲刺标语、居民楼办公地址

能力边界与诚实说明

输出为辅助求职者向 HR/业务方核实的决策清单，不构成法律意见或企业定性判决。

高频常见问题（FAQ）

如果网上几乎搜不到某家公司的负面消息，sherlock-company 会判定它安全吗？

不会。工具明确规定“零结果绝不等同于零风险”，信息缺失会被严格标为 unknown（还不知道），并提示你在签 Offer 前向 HR 或业务面试官直接核实。

公司调查大师最核心帮你查哪几类常见踩坑点？

重点核查四大主体一致性（品牌/招聘/劳动合同/社保主体），并默认触发三类预警检查：少于 100 人的初创规模风险、密集感恩/业绩冲刺标语、居民楼办公地址。

这份四态调查档案可以当成法律维权证据或企业黑名单定性吗？

不可以。输出仅供求职者本人核实沟通使用，不构成任何法律意见或官方企业定性判决。
